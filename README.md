# Gerador de Senhas

Um projeto simples em **Java** que gera senhas seguras e aleatórias. Este é um dos meus primeiros projetos publicados no GitHub, destinado a praticar lógica de programação e manipulação de strings.

## Funcionalidades

- Gera senhas aleatórias.
- Permite configurar o tamanho da senha.
- Combina letras maiúsculas, minúsculas, números e símbolos (dependendo da implementação).

## Tecnologias

- Java
- IDE recomendada: IntelliJ IDEA ou Eclipse
